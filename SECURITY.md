# Security Policy

## Supported version

Security fixes are provided for the latest release on `main`.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Include a
clear description, affected files or workflow, reproduction steps, impact, and
any safe mitigation you identified.

Do not open a public issue for a vulnerability that could expose credentials,
unsafe agent behavior, private project data, or a bypass of an authorization
or validation rule.
