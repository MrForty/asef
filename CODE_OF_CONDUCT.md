# Code of Conduct

## Our pledge

We want ASEF to be a respectful, useful place for people who build software
with coding agents. We welcome constructive contributions regardless of
experience, background, identity, or the tools a contributor uses.

## Expected behavior

- Discuss ideas and changes in good faith.
- Give specific, actionable feedback.
- Respect different technical opinions and project constraints.
- Keep security-sensitive details private until maintainers can assess them.

## Unacceptable behavior

Harassment, personal attacks, discriminatory language, threats, deliberate
disruption, or publishing private information without permission are not
accepted.

## Enforcement

Report concerns privately to the repository owner through the
[`MrForty` GitHub profile](https://github.com/MrForty). Do not include sensitive
details in a public issue. The maintainer may warn, edit, remove, or block
content or participants when needed to protect the community.
